Progress & Stepper

Indicadores visuais de progresso para uploads, carregamento e navegação de etapas. Conjunto completo baseado no Figma com ProgressBarComponent (linear e segmentado), ProgressCircleComponent (circular) e StepperComponent (horizontal numérico, horizontal com ícones e vertical com progresso embutido).

Documentação da API

<orc-progress-bar> (ProgressBarComponent)

Propriedade / Input Tipo Padrão Descrição
value number 0 Valor percentual de progresso exato (de 0 a 100).
mode 'determinate' | 'indeterminate' 'determinate' Modo quantificável (determinado) ou contínuo de carregamento (indeterminado).
variant 'primary' | 'neutral' | 'success' | 'warning' | 'error' | 'danger' 'primary' Variante de cor semântica do Design System Orchestra.
size 'sm' | 'md' | 'lg' 'md' Espessura da barra (sm: 4px, md: 8px, lg: 12px).
label string '' Rótulo textual exibido acima da barra no canto esquerdo.
showValue boolean false Exibe o valor numérico percentual no canto superior direito.
valuePrefix / valueSuffix string '' / '%' Prefixo e sufixo aplicados à formatação da porcentagem textual.
rounded boolean true Aplica cantos arredondados na trilha e no preenchimento.
segments number 0 Número total de etapas para renderizar no formato de barra segmentada.
currentSegment number 0 Índice da etapa ativa atual na barra segmentada (1 a N).
customHeight string | number '' Altura customizada para a barra (ex: '5px').
customColor / customTrackColor string '' Cores hexadecimais ou CSS customizadas para preenchimento e trilha.
ariaLabel / ariaValueText string '' Atributos de acessibilidade WCAG (role="progressbar").

<orc-progress-circle> (ProgressCircleComponent)

Propriedade / Input Tipo Padrão Descrição
value number 0 Valor percentual de progresso exato (de 0 a 100).
mode 'determinate' | 'indeterminate' 'determinate' Modo determinado com arco proporcional ou indeterminado com rotação contínua.
variant 'primary' | 'neutral' | 'success' | 'warning' | 'error' | 'danger' 'primary' Variante de cor semântica do Design System.
size 'sm' | 'md' | 'lg' | 'xl' | number 'md' Diâmetro do círculo (sm: 32px, md: 48px, lg: 64px, xl: 96px ou número em px).
strokeWidth number auto Espessura do traço SVG em pixels.
showValue boolean false Exibe o valor numérico centralizado no círculo.
rounded boolean true Extremidades do traço arredondadas (stroke-linecap="round").
customColor / customTrackColor string '' Cores customizadas para o arco de preenchimento e para a trilha.
ariaLabel / ariaValueText string '' Atributos de acessibilidade WCAG (role="progressbar").

<orc-stepper> (StepperComponent)

Propriedade / Input / Output Tipo Padrão Descrição
steps StepItem[] [] Array de passos contendo title, subtitle, icon, progress e status.
currentStep model<number> 0 Índice da etapa ativa atual (0-indexed) com suporte a Two-Way Binding.
orientation 'horizontal' | 'vertical' 'horizontal' Orientação visual do fluxo de etapas.
type 'numeric' | 'icon' 'numeric' Estilo visual dos marcadores (números ordinais ou ícones/símbolos).
clickable boolean true Habilita interação e navegação ao clicar diretamente nas etapas.
linear boolean false Impede pular etapas para a frente sem completar as anteriores.
stepChange output<{ step: StepItem, index: number }> - Evento emitido quando uma etapa é clicada/selecionada.

Exemplo de Importação e Uso

Exemplo Angular Standalone Completo
import { ProgressBarComponent, ProgressCircleComponent, StepperComponent } from '@orc/ds';

@Component({
  standalone: true,
  imports: [ProgressBarComponent, ProgressCircleComponent, StepperComponent],
  template: `
    <!-- 1. Barra de progresso determinada -->
    <orc-progress-bar [value]="78" variant="primary" label="Upload" [showValue]="true" />

    <!-- 2. Círculo de progresso -->
    <orc-progress-circle [value]="50" variant="success" size="md" [showValue]="true" />

    <!-- 3. Barra segmentada -->
    <orc-progress-bar [segments]="3" [currentSegment]="1" variant="success" />

    <!-- 4. Stepper Horizontal ou Vertical -->
    <orc-stepper [steps]="minhasEtapas" [currentStep]="etapaAtiva" orientation="vertical" />
  `
})
export class MeuComponente {
  etapaAtiva = 1;
  minhasEtapas = [
    { title: 'Upload', subtitle: 'Arquivo enviado com sucesso', icon: '✓' },
    { title: 'Processando', subtitle: 'Validando dados...', progress: 78 },
    { title: 'Finalização', subtitle: 'Aguardando etapa anterior' },
  ];
}
