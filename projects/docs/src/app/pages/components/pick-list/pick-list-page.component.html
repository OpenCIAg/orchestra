PickList

Transfira opções entre duas listas com seleção por teclado, filtros independentes, ações por botão e suporte a arrastar itens habilitados.

Exemplo interativo

O estado de origem e destino é controlado pelo consumidor com two-way binding.

Contrato de uso

Use valores string estáveis em cada opção e mantenha os nomes das duas listas.

02 / 02

Seleção e transferência

Enter ou Espaço seleciona uma opção. Ctrl/Command adiciona outra seleção por padrão; desative metaKeySelection para alternar itens sem modificadores. Arraste itens habilitados ou use as ações.

Filtros acessíveis

Cada painel tem um nome e um filtro próprio. Ações “todos” ignoram o filtro, mas respeitam itens desabilitados.

Layout estreito

Em telas estreitas, as listas ficam empilhadas e os quatro controles de transferência passam para uma linha compacta.
