Referência de API: Button

Propriedade Tipo Padrão Descrição
variant input 'primary' | 'secondary' | 'outline' | 'ghost' | 'link' | 'danger' 'primary' Estilo visual de preenchimento e borda do botão.
severity input 'primary' | 'secondary' | 'outline' | 'ghost' | 'link' | 'danger' | undefined undefined Variante com precedência sobre variant.
size input 'sm' | 'md' | 'lg' 'md' Dimensões do botão (Small 32px, Medium 40px, Large 48px).
disabled input boolean false Define o estado desabilitado de clique e interações visuais.
loading input boolean false Exibe spinner centralizado, desabilita cliques e preserva a largura.
text input boolean false Aplica a apresentação de botão textual.
outlined input boolean false Ativa o modificador visual contornado.
raised input boolean false Ativa a elevação visual do botão.
rounded input boolean false Aplica bordas totalmente arredondadas.
plain input boolean false Remove o preenchimento da apresentação do botão.
fullWidth input boolean false Se verdadeiro, o botão ocupa 100% da largura do contêiner pai.
fluid input boolean false Aplica a classe fluida e ocupa a largura disponível.
link input boolean false Força a variante de link sobre severity e variant.
icon input string | undefined undefined Ícone genérico por classe ou SVG sanitizado.
iconPos input 'left' | 'right' | 'top' | 'bottom' 'left' Posiciona o ícone genérico.
iconLeft input string | undefined undefined Nome de classe ou string contendo SVG para ícone esquerdo.
iconRight input string | undefined undefined Nome de classe ou string contendo SVG para ícone direito.
loadingIcon input string | undefined undefined Substitui o spinner com ícone por classe ou SVG sanitizado.
badge input string | number | undefined undefined Exibe uma contagem em cápsula junto ao conteúdo.
badgeClass input string '' Classes adicionais para a cápsula de contagem.
iconOnly input boolean false Se verdadeiro, oculta qualquer texto e mantém apenas os ícones. Forneça ariaLabel para o nome acessível.
ariaLabel input string | undefined undefined Nome acessível explícito, necessário em botões sem rótulo textual acessível.
id input string | undefined undefined ID aplicado ao botão nativo.
tabindex input number | undefined undefined Índice nativo de navegação por teclado, quando configurado.
ariaLabelledBy input string | undefined undefined ID externo que nomeia o botão.
ariaExpanded input boolean | undefined undefined Estado expandido comunicado a tecnologias assistivas.
ariaControls input string | undefined undefined ID do conteúdo controlado pelo botão.
form input string | undefined undefined Associa o botão a um formulário pelo ID nativo.
styleClass input string '' Classes extras aplicadas ao botão.
style input Record<string, string | number> | undefined undefined Estilos inline aplicados ao botão nativo.
type input 'button' | 'submit' | 'reset' 'button' Atributo HTML nativo do botão.
clicked output MouseEvent — Alias do evento de clique do componente. O evento DOM nativo continua disponível como (click) sem duplicação.
onFocus output FocusEvent — Encaminha o evento nativo de foco.
onBlur output FocusEvent — Encaminha o evento nativo de saída de foco.
