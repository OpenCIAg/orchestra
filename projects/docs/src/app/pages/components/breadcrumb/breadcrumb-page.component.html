Referência de API

<app-breadcrumb>

Propriedade Tipo Padrão Descrição
items input BreadcrumbItemData[] undefined Array opcional de itens para renderização orientada a dados.
variant input 'default' | 'underlined' 'default' Estilo do item final (texto em negrito ou sublinhado azul).
separator input 'chevron' | 'slash' | 'arrow' | string 'chevron' Símbolo divisor entre os itens do caminho.
maxItems input number undefined Limite máximo de itens antes de colapsar níveis intermediários em ....
itemClick output { item, index } — Evento emitido ao clicar em um item navegável.

<app-breadcrumb-item>

Propriedade Tipo Padrão Descrição
label input string '' Texto descritivo do item.
routerLink input string | any[] undefined Rota Angular para navegação via RouterLink.
href input string undefined Link URL nativo externo.
active input boolean false Define o item como página atual (adiciona aria-current="page").
disabled input boolean false Desabilita a interação com o link.
icon input string undefined Ícone SVG opcional no início do item (ex: 'home').
