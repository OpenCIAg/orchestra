Exemplos de Código (TypeScript)

// 1. Injetar o ToastService
import { ToastService } from '@orchestra/ds';

@Component({ ... })
export class MeuComponente {
  private readonly toastService = inject(ToastService);

  salvarDados() {
    // Disparo simples de sucesso
    this.toastService.success('Seus dados foram salvos com sucesso!');

    // Ou com opções avançadas e ação de desfazer
    this.toastService.show({
      type: 'info',
      title: 'Item excluído',
      message: 'Você pode desfazer esta ação dentro de 8 segundos.',
      duration: 8000,
      position: 'bottom-right',
      action: {
        label: 'Desfazer',
        icon: 'undo',
        onClick: (toast) => this.restaurarItem(),
      },
    });
  }
}

Documentação da API

Propriedade / Opção Tipo Padrão Descrição
type 'success' | 'info' | 'warning' | 'error' | 'loading' | 'notification' 'info' Tipo de notificação e ícone semântico correspondente.
title string '' Título principal do toast.
message string '' Texto descritivo ou detalhes da mensagem.
position 'top-right' | 'top-left' | 'top-center' | 'bottom-right' | 'bottom-left' | 'bottom-center' 'top-right' Posição na viewport onde o toast será empilhado.
duration number 5000 Tempo em milissegundos para auto-dismiss (0 para desativar).
showProgressBar boolean false Exibe a barra de progresso visual de tempo restante na base do toast.
pauseOnHover boolean true Pausa o contador de tempo quando o ponteiro estiver sobre o toast.
dismissible boolean true Exibe o botão 'X' de fechar.
action { label: string, icon?: string, onClick: Function } undefined Botão de ação interativa incorporado no toast.
