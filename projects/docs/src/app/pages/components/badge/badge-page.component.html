Referência de API

Propriedade Tipo Padrão Descrição
variant input 'soft' | 'solid' | 'outline' | 'dot' | 'ghost' 'soft' Estilo visual de preenchimento e borda do badge.
status input BadgeStatus 'primary' Cor semântica de status ('primary', 'success', 'warning', 'danger', 'info', etc.).
size input 'sm' | 'md' | 'lg' 'md' Dimensões do badge (18px, 22px ou 28px).
text input string '' Texto do rótulo exibido dentro do badge.
count input number undefined Valor numérico formatado automaticamente com limite de overflow.
maxCount input number 99 Limite máximo exibido antes de aplicar formato +max (ex: +99).
showDefaultIcon input boolean false Exibe ícone SVG contextualizado conforme o status informado.
dismissible input boolean false Adiciona um botão 'x' para remoção/dismiss da tag.
pill input boolean false Aplica bordas totalmente arredondadas (estilo pílula).
dismiss output MouseEvent — Evento disparado ao clicar no botão de fechar.
