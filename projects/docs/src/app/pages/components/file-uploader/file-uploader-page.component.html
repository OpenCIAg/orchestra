Referência de API

Integração nativa com ReactiveFormsModule e ControlValueAccessor.

Propriedade Tipo Padrão Descrição
accept input string '' Formatos aceitos (ex: image/*,.pdf).
multiple input boolean true Permite seleção múltipla.
maxFiles input number 10 Limite máximo de arquivos permitidos.
maxFileSize input number 5 Tamanho máximo por arquivo (em MB).
label input string 'Clique ou arraste...' Texto principal do drag and drop.
subLabel input string 'Suporta imagens e PDFs' Texto secundário (instruções extras).
disabled input boolean false Desabilita o componente inteiro.
forceDragover input boolean false Força visualmente o estado de dragover.
