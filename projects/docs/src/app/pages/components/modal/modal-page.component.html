Modal / Dialog

Documentação da API

<orc-modal>

Propriedade, model ou evento Tipo Padrão Descrição
isOpen model<boolean> false Define se o modal está aberto. Suporta Two-way binding (`[(isOpen)]`).
visible model<boolean> false Alias compatível para controlar a visibilidade. Prefira apenas um dos models por instância.
header string undefined Texto de cabeçalho. Também é possível projetar conteúdo com o atributo modal-header.
modal boolean true Usa showModal() para colocar o diálogo na top layer e restringir a interação ao modal.
closeOnEscape boolean true Permite fechar com Escape. Para fluxos obrigatórios, defina false e mantenha uma ação interna para concluir ou cancelar.
size 'sm' | 'md' | 'lg' | 'xl' | 'fullScreen' | 'custom' 'md' Largura máxima e porte do modal.
status 'neutral' | 'danger' 'neutral' Define o tratamento visual do diálogo; use danger para ações destrutivas.
inline boolean false Renderiza o elemento sem abrir a camada modal nativa. Útil para exemplos e composições embutidas.
position 'center' | 'top' | 'bottom' | 'left' | 'right' | 'topleft' | 'topright' | 'bottomleft' | 'bottomright' 'center' Escolhe o alinhamento do diálogo na viewport.
closeOnBackdropClick / dismissableMask boolean true Permite fechar ao clicar na máscara. As duas opções precisam permanecer habilitadas.
showCloseButton / closable boolean true Controla o botão de fechar no cabeçalho.
showHeader boolean true Controla a região de cabeçalho; sem título visível, forneça ariaLabel ou ariaLabelledBy.
closeIcon, closeAriaLabel, closeTabindex string, string, string '×', 'Close dialog', 0 Personaliza o ícone, o nome acessível e a ordem de foco do controle de fechamento.
maximizeIcon, minimizeIcon, maximizeAriaLabel, restoreAriaLabel string '+', '−', 'Maximize dialog', 'Restore dialog' Personaliza os símbolos e nomes acessíveis dos controles de maximização.
focusOnShow boolean true Move o foco para o primeiro controle habilitado ao abrir.
focusTrap boolean true Mantém a navegação por Tab dentro do diálogo modal.
blockScroll boolean true Bloqueia a rolagem do documento enquanto o modal está aberto.
maximizable / maximized boolean / model<boolean> false Exibe o controle de maximização e expõe o estado atual.
ariaLabel, ariaLabelledBy, ariaDescribedBy, role string 'dialog' para role Configura o nome e a descrição acessíveis. Um cabeçalho projetado fornece o nome padrão quando está visível.
id string undefined Define um identificador estável para a instância.
style string | Record<string, string | number> undefined Aplica estilos ao elemento de diálogo.
styleClass, contentStyle, contentStyleClass string, Record<string, string | number>, string '', undefined, '' Aplica classes ao diálogo e estilos ou classes à região de conteúdo.
zIndex / baseZIndex / autoZIndex number / number / boolean 1000 / 1000 / true Define a prioridade de empilhamento entre superfícies; o navegador controla a ordem da top layer nativa.
closed output<void> - Evento disparado sempre que o modal se fecha.
onShow, onHide, onMaximize output<void> / output<MaximizeEvent> - Notificam a abertura, o fechamento e a alteração do estado maximizado; o evento carrega maximized: boolean.

As opções de compatibilidade draggable, resizable, appendTo, breakpoints, maskStyle, maskStyleClass, keepInViewport, minX, minY, transitionOptions e rtl estão depreciadas e não alteram o comportamento. Use os atributos de posicionamento, foco e apresentação documentados acima.

ModalService

Método Assinatura Descrição
open() open<T>(component: Type<T>, inputs?: Record<string, unknown>): ModalRef<T> Instancia e injeta um componente dinâmico no DOM. O componente fornecido deve conter o <orc-modal> internamente para acionar o Top Layer.
