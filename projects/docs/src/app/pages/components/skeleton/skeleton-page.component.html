Propriedade Tipo Padrão Descrição
variant input 'text' | 'circular' | 'rectangular' 'text' Formato geométrico do placeholder de carregamento.
animation input 'shimmer' | 'pulse' | 'none' 'shimmer' Efeito visual de animação durante o carregamento.

height input string | number '14px' / '40px' / '96px' Altura customizada do componente.
borderRadius input string '8px' / '50%' Raio de arredondamento das bordas.
ariaLabel input string 'Carregando conteúdo...' Texto acessível fornecido a leitores de tela.
