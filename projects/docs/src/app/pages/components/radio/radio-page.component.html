Acessibilidade & Teclado (WCAG 2.1 AA)

role="radiogroup"

Agrupa semanticamente as opções e permite que leitores de tela anunciem o total de itens e o item ativo.

role="radio" / aria-checked

Comunicação exata do estado marcado/desmarcado e atributos aria-disabled e aria-invalid.

Roving Tabindex

Apenas a opção selecionada (ou a primeira habilitada) recebe tabindex="0", garantindo navegação limpa.

Tecla Comportamento
Tab / Shift + Tab Entra e sai do grupo de radio buttons, focando o item atualmente selecionado.
↓ / → Move a seleção e o foco para a próxima opção habilitada do grupo.
↑ / ← Move a seleção e o foco para a opção anterior habilitada do grupo.
Espaço Marca a opção em foco caso ainda não esteja selecionada.

Documentação da API

app-radio-group

Propriedade Tipo Padrão Descrição
value model<any> null Valor bidirecionalmente vinculado ao grupo (compatível com ngModel / CVA).
layout input<'vertical' | 'horizontal'> 'vertical' Direção visual das opções (coluna ou linha).
label input<string> '' Título ou legenda acessível do grupo.
hint input<string> '' Texto de ajuda exibido abaixo do rótulo do grupo.
disabled input<boolean> false Desabilita todas as opções do grupo simultaneamente.
error input<boolean> false Ativa visual de validação de erro no grupo.
errorMessage input<string> '' Mensagem de erro exibida quando error for verdadeiro.
valueChange output<any> - Evento emitido na mudança de valor selecionado.

app-radio-button

Propriedade Tipo Padrão Descrição
value input<any> undefined Valor único correspondente a esta opção.
label input<string> '' Texto do rótulo da opção (ou via projeção de conteúdo).
description input<string> '' Texto auxiliar exibido abaixo do rótulo.
disabled input<boolean> false Desabilita individualmente este radio button.
select output<any> - Evento emitido quando a opção for selecionada.
