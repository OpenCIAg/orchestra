OrderList

Selecione, filtre e reordene itens mantendo o valor controlado pelo consumidor. Itens desabilitados permanecem protegidos durante o uso.

Exemplo interativo

Clique em um item para selecioná-lo, use as setas para navegar e os controles de posição para reordenar.

01 / 02
Selecionados: {{ selectedLabels() }}
Ordem: {{ orderLabels() }} Use Enter ou Espaço para selecionar; Home, End e as setas movem o foco.

Contrato de uso

O valor e a seleção são controlados pelo consumidor para que a ordem possa ser persistida.

02 / 02

Seleção e teclado

O modo múltiplo permite marcar itens independentemente. O foco segue um único item habilitado por vez.

Filtro e ordem

Filtre pelos rótulos e use os botões nomeados para mover o item selecionado para cima ou para baixo.

Itens desabilitados

Itens desabilitados e o estado geral desabilitado não aceitam seleção, foco ou reordenação.
