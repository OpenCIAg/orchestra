Referência de API

Propriedade Tipo Padrão Descrição
size input 'sm' | 'md' | 'lg' 'md' Tamanho pré-definido (sm: 16px, md: 24px, lg: 40px).
customSize input string | number '' Dimensão customizada em pixels ou porcentagem (ex: 32 ou '32px').
variant input 'primary' | 'secondary' | 'neutral' | 'white' 'primary' Variação cromática do indicador.
type input 'ring' | 'star' | 'dots' 'ring' Estilo da animação do indicador.
text input string '' Texto descritivo opcional exibido junto ao spinner.
textPosition input 'right' | 'bottom' 'right' Posição do texto descritivo em relação ao indicador.
fullScreen input boolean false Ativa o modo de bloqueio e carregamento em tela cheia com overlay.
backdrop input boolean true Exibe fundo semitransparente com desfoque no modo tela cheia.
ariaLabel input string 'Carregando...' Texto acessível lido por leitores de tela (WCAG).
