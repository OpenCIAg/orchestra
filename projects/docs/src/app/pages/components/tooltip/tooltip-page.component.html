Referência de API

[uiTooltip] (Diretiva)

Propriedade Tipo Padrão Descrição
uiTooltip / orcTooltip input string '' Texto informativo exibido dentro do tooltip.
tooltipPosition input 'top' | 'bottom' | 'left' | 'right' 'top' Posição preferencial do tooltip em relação ao elemento de gatilho.
tooltipTheme input 'dark' | 'light' 'dark' Tema visual do tooltip (darkmode com fundo preto ou lightmode com fundo cinza).
tooltipShowDelay input number 150 Tempo de atraso em milissegundos antes de exibir o tooltip.
tooltipHideDelay input number 100 Tempo de atraso em milissegundos antes de ocultar o tooltip.
tooltipDisabled input boolean false Desabilita a exibição do tooltip.
