Orchestra Design System

Um sistema de design limpo, acessível e consistente para produtos Angular. Este guia documenta os fundamentos visuais da marca — das cores à tipografia — garantindo coerência em todos os pontos de contato do produto.

Composição de referência

Fundamentos que se comportam como produto.

Os mesmos primitives usados nos showcases estão disponíveis para a sua aplicação Angular.

Princípios

⬡

Clareza

Cada elemento tem uma função clara. Removemos tudo que não agrega valor ao usuário.

 ◎

Consistência

Tokens únicos que se propagam por todo o sistema, garantindo harmonia visual.

 ⬔

Acessibilidade

Contraste mínimo 4.5:1, foco visível e semântica HTML correta em todos os componentes.

 ◈

Escala

Projetado para crescer. Cada decisão de token suporta temas e extensões futuras.

Boas Práticas

Diretrizes recomendadas para garantir coerência e qualidade visual em todos os produtos.

✓ Utilize sempre as variáveis CSS (tokens) para cores, espaçamentos, tipografia e raios de borda.
✓ Garanta que todos os elementos interativos tenham foco visível e contraste adequado para acessibilidade (WCAG AA).
✓ Mantenha a hierarquia tipográfica consistente usando os pesos e escalas predefinidos da família Poppins.
✓ Mantenha espaçamento mínimo de 16px ao redor de marcas, ícones e componentes isolados.

O que evitar

Práticas que prejudicam a consistência e a experiência visual do sistema de design.

✕ Não declare cores hexadecimais avulsas ou hardcoded diretamente nos estilos locais dos componentes.
✕ Não distorça, altere proporções ou rotacione logos e ícones da marca.
✕ Não utilize combinações com contraste inferior a 4.5:1 entre textos e plano de fundo.
✕ Não crie espaçamentos arbitrários fora da escala de 4px (múltiplos de 0.25rem).
