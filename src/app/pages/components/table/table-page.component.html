Documentação da API

<orc-table> (TableComponent)

Propriedade / Input / Output Tipo Padrão Descrição
data T[] [] Array de dados tipados a serem renderizados na tabela.
selectable boolean false Exibe a primeira coluna com Checkbox para seleção individual e em massa.
selectedRows model<T[]> [] Linhas selecionadas atualmente com suporte a Two-Way Binding ([(selectedRows)]).
rowKey string 'id' Nome da propriedade identificadora única do registro de cada linha.
sortColumn model<string> '' Chave da coluna ordenada atualmente (Two-Way Binding).
sortDirection model<'asc' | 'desc' | 'none'> 'none' Sentido da ordenação atual (Two-Way Binding).
paginated boolean false Exibe o rodapé com PaginatorComponent integrado para navegação de páginas.
pageSize model<number> 5 Quantidade de registros exibidos por página.
currentPage model<number> 1 Página ativa atual (1-indexed).
striped boolean false Aplica estilo zebrado alternado nas linhas da tabela.
bordered boolean true Adiciona moldura externa e bordas às células.
hoverable boolean true Aplica efeito visual de realce quando o mouse passa sobre as linhas.
loading boolean false Exibe estado de carregamento com linhas de SkeletonComponent.
emptyTitle / emptyMessage string 'Nenhum dado...' Textos exibidos no estado vazio quando data não possui registros.
sortChange output<TableSortEvent> - Disparado quando o usuário clica no cabeçalho para ordenar.
selectionChange output<T[]> - Disparado sempre que a lista de linhas selecionadas é alterada.
rowClick output<T> - Disparado quando uma linha é clicada.

<orc-column> (ColumnDirective)

Propriedade / Input Tipo Padrão Descrição
key string Obrigatório Chave identificadora do campo no objeto de dados.
header string '' Texto exibido no cabeçalho da coluna.
sortable boolean false Torna a coluna ordenável ao clicar no cabeçalho.
width string '' Largura customizada para a coluna (ex: '160px', '25%').
align 'left' | 'center' | 'right' 'left' Alinhamento do texto e conteúdo das células.

Diretivas de Template Célula (*orcCellDef / *orcHeaderCellDef)

Diretiva Variáveis Disponíveis no Contexto Descrição
*orcCellDef="let row; let i = index; let col = column" row (dado da linha), index (índice da linha), column (diretiva da coluna), value (valor do campo) Permite renderizar componentes customizados (Badges, Avatars, Ações) no corpo da célula.
*orcHeaderCellDef="let col = column" column (diretiva da coluna) Permite customizar o conteúdo HTML do cabeçalho da coluna.

Exemplo de Uso com BadgeComponent

Exemplo Angular Standalone Completo
import { Component, signal } from '@angular/core';
import { TableComponent, ColumnDirective, CellDefDirective } from '@orc/ds';
import { BadgeComponent } from '@orc/ds';

@Component({
  standalone: true,
  imports: [TableComponent, ColumnDirective, CellDefDirective, BadgeComponent],
  template: `
    <orc-table
      [data]="usuarios()"
      [selectable]="true"
      [(selectedRows)]="linhasSelecionadas"
      [paginated]="true"
      [pageSize]="5"
    >
      <!-- Coluna de Texto Simples -->
      <orc-column key="name" header="Título" [sortable]="true" />
      <orc-column key="role" header="Conteúdo" [sortable]="true" />

      <!-- Coluna com BadgeComponent Integrado -->
      <orc-column key="status" header="Status" [sortable]="true" align="center">
        <ng-template orcCellDef let-row>
          <app-badge
            variant="soft"
            [status]="row.status"
            [text]="row.statusLabel"
            [pill]="true"
          />
        </ng-template>
      </orc-column>
    </orc-table>
  `
})
export class MeuComponente {
  linhasSelecionadas = signal([]);
  usuarios = signal([
    { id: 1, name: 'Orquestra Tech', role: 'Desenvolvimento', status: 'success', statusLabel: 'Sucesso' },
    { id: 2, name: 'Design System', role: 'UI/UX Design', status: 'warning', statusLabel: 'Aviso' },
    { id: 3, name: 'API Gateway', role: 'Infraestrutura', status: 'info', statusLabel: 'Novo' },
    { id: 4, name: 'Analytics', role: 'Data Science', status: 'danger', statusLabel: 'Erro' },
  ]);
}
