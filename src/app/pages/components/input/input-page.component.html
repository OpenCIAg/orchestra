Documentação da API

<orc-input> (InputComponent)

Propriedade / input / output Tipo Padrão Descrição
value model<string | number> '' Valor textual ou numérico do campo (Two-Way Binding [(value)]).
mask string '' Padrão de máscara para formatação (ex: '000.000.000-00', '(00) 00000-0000', '00000-000'). Tokens: 0 ou 9 para dígitos, A para letras, * para alfanumérico.
unmaskValue boolean false Quando true, emite o valor sem os caracteres literais da máscara para o signal/formControl.
type 'text' | 'password' | 'email' | 'number' | 'search' | 'tel' | 'url' 'text' Tipo do elemento HTML input nativo.
size 'sm' | 'md' | 'lg' 'md' Tamanho e espaçamentos internos do campo.
status 'default' | 'error' | 'success' 'default' Estado visual de validação semântica.
label string '' Texto do rótulo associado semanticamente ao campo com acessibilidade WCAG.
placeholder string 'Digite algo...' Texto de dica exibido quando o campo está vazio.
helperText string '' Mensagem de instrução exibida abaixo do campo via aria-describedby.
errorMessage string '' Mensagem de erro exibida quando status="error".
clearable boolean false Exibe botão para limpar o valor com um clique (ativado por padrão em type="search").
showCharCount boolean false Exibe a contagem de caracteres e limite máximo no rodapé.
maxLength number undefined Limite máximo de caracteres aceito pelo campo (definido automaticamente pela máscara se informada).
prefixText / suffixText string '' Textos fixos exibidos como prefixo ou sufixo dentro da caixa do input.
disabled / readonly boolean false Desativa o campo ou define modo apenas leitura.
inputChange output<string | number> - Disparado a cada caractere digitado ou alteração de valor.
clear output<void> - Disparado quando o botão de limpar é acionado.

<orc-textarea> (TextareaComponent)

Propriedade / input Tipo Padrão Descrição
value model<string> '' Valor textual do textarea (Two-Way Binding).
rows number 4 Quantidade inicial de linhas visíveis do textarea.
resize 'vertical' | 'none' | 'both' | 'horizontal' 'vertical' Comportamento do redimensionador manual do navegador.
autoResize boolean false Ajusta automaticamente a altura com base na quantidade de linhas digitadas.

Exemplos de código

Exemplo de uso com Angular Standalone & Reactive Forms
import { Component } from '@angular/core';
import { ReactiveFormsModule, FormControl, FormGroup, Validators } from '@angular/forms';
import { InputComponent, TextareaComponent } from '@orc/ds';

@Component({
  standalone: true,
  imports: [ReactiveFormsModule, InputComponent, TextareaComponent],
  template: `
    <form [formGroup]="userForm">
      <!-- Campo de Texto com Máscara de CPF -->
      <orc-input
        formControlName="cpf"
        label="CPF"
        mask="000.000.000-00"
        placeholder="000.000.000-00"
        [required]="true"
      />

      <!-- Senha com Toggle de Visibilidade -->
      <orc-input
        formControlName="password"
        type="password"
        label="Senha"
      />

      <!-- Textarea Multilinha -->
      <orc-textarea
        formControlName="comments"
        label="Comentários adicionais"
        [maxLength]="300"
        [showCharCount]="true"
      />
    </form>
  `
})
export class MeuFormularioComponent {
  userForm = new FormGroup({
    cpf: new FormControl('', [Validators.required]),
    password: new FormControl('', [Validators.required]),
    comments: new FormControl(''),
  });
}
