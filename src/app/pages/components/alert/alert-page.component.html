Documentação da API

Input / Property Tipo Padrão Descrição
severity 'info' | 'success' | 'warning' | 'error' 'info' Nível de severidade e cores semânticas do alerta.
variant 'subtle' | 'soft' | 'filled' | 'outline' 'subtle' Estilo visual de preenchimento ou contorno.
title string '' Título principal do alerta em negrito/médio.
message string '' Texto descritivo do alerta.
showIcon boolean true Exibe ou oculta o ícone correspondente à severidade.
dismissible boolean false Exibe o botão 'X' de fechar.
role string 'alert' | 'status' Atributo ARIA role para conformidade de acessibilidade WCAG.
Output / Evento Tipo Descrição
onClose output<MouseEvent> Emitido quando o botão de fechar é acionado pelo usuário.
closed output<void> Emitido após a alteração do estado de visibilidade.
