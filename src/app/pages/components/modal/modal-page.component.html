Documentação da API

<orc-modal>

Propriedade / Model Tipo Padrão Descrição
isOpen model<boolean> false Define se o modal está aberto. Suporta Two-way binding (`[(isOpen)]`).
size 'sm' | 'md' | 'lg' | 'xl' | 'fullScreen' 'md' Largura máxima e porte do modal.
closeOnBackdropClick boolean true Se verdadeiro, clicar no escuro do fundo fecha o modal automaticamente.
showCloseButton boolean true Renderiza o botão "X" no canto superior direito do cabeçalho.
zIndex number 1000 Prioridade de empilhamento caso hajam múltiplos modais. (Natível <dialog> top layer costuma anular necessidade).
closed output<void> - Evento disparado sempre que o modal se fecha.

ModalService

Método Assinatura Descrição
open() open<T>(component: Type<T>, inputs?: Record<string, unknown>): ModalRef<T> Instancia e injeta um componente dinâmico no DOM. O componente fornecido deve conter o <orc-modal> internamente para acionar o Top Layer.
