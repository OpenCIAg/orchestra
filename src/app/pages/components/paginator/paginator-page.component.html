Referência de API

<app-paginator>

Propriedade Tipo Padrão Descrição
totalItems input number 0 Quantidade total de itens no conjunto de dados.
pageSize model number 10 Quantidade de registros exibidos por página (two-way binding).
currentPage model number 1 Número da página atual selecionada (1-indexed, two-way binding).
pageSizeOptions input number[] [10, 20, 50] Opções disponíveis no dropdown de itens por página.
showPageSizeSelector input boolean true Exibe ou oculta o seletor de itens por página.
showFirstLastButtons input boolean false Exibe botões rápidos para a primeira e última página.
showPrevNextButtons input boolean true Exibe os botões de navegação anterior e próximo.
showTotalInfo input boolean false Exibe o texto informativo de intervalo ("1–20 de 120 itens").
size input 'sm' | 'md' | 'lg' 'md' Dimensões visuais dos botões e seletores.
disabled input boolean false Desabilita todas as interações e cliques no paginador.
previousLabel input string 'Anterior' Texto do botão de página anterior.
nextLabel input string 'Próximo' Texto do botão de próxima página.
itemsPerPageLabel input string 'Página' Sufixo textual no dropdown (ex.: "20 / página").
pageChange output EventEmitter<PageChangeEvent> — Emitido quando a página atual ou o tamanho da página é modificado.
pageSizeChange output EventEmitter<number> — Emitido exclusivamente quando o tamanho da página é modificado.
