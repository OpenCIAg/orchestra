Componentes · Inputs

Switch / Toggle

Controle de alternância de estado binário (ativado/desativado) com animação fluida, suporte nativo a formulários reativos, Signals API (`model()`, `input()`, `output()`), múltiplos tamanhos, posicionamento de rótulo e total conformidade com WCAG 2.1 AA.

Propriedades e controles

Componentes planos

Ativado (checked) Fundo #1C6AED, thumb branco à direita, 32×18.4px (Figma 382:5036)
Desativado (unchecked) Fundo #D9D9D9 cinza neutro, thumb branco à esquerda
Desabilitado e ativo Opacidade 0.5, cursor not-allowed, cores atenuadas
Desabilitado e inativo Fundo cinza claro atenuado com cursor bloqueado
Validação de erro Trilha com cor #FB2C36 e mensagem vinculada por aria-describedby
Rótulo à esquerda (start) Texto posicionado antes do controle switch

Exemplos de código

1. Uso básico com two-way model signal
<!-- Two-way binding com Signals -->
<app-switch [(checked)]="notificacoesAtivas" label="Ativar notificações" />

<!-- Com helper text e tamanho pequeno -->
<app-switch
  [(checked)]="modoEconomia"
  size="sm"
  label="Modo de economia"
  description="Reduz o consumo de dados em segundo plano"
/>
2. Formulários reativos com ControlValueAccessor
<app-switch
  formControlName="autenticacaoDoisFatores"
  label="Autenticação em duas etapas"
  [error]="form.get('autenticacaoDoisFatores')?.invalid && form.get('autenticacaoDoisFatores')?.touched"
  errorMessage="Obrigatoriedade de segurança para administradores"
/>
3. Rótulo à esquerda (labelPosition="start")
<app-switch
  [(checked)]="visibilidadePerfil"
  labelPosition="start"
  label="Perfil visível publicamente"
/>

Referência de API (inputs, models e outputs)

Propriedade Tipo Padrão Descrição
checked model boolean false Estado binário do switch (ativo/inativo). Suporta two-way binding [(checked)].
size input 'sm' | 'md' | 'lg' 'md' Tamanho da chave e do thumb (md = 32px conforme especificação do Figma).
labelPosition input 'start' | 'end' 'end' Posição do rótulo em relação à chave (à esquerda ou à direita).
label input string '' Texto do rótulo com clique integrado para alternância.
description input string '' Texto de apoio ou orientação exibido abaixo do rótulo.
disabled input boolean false Desabilita a interação com o switch e aplica opacidade 0.5.
error input boolean false Ativa o estado visual de erro e aria-invalid="true".
errorMessage input string '' Mensagem de validação de erro exibida abaixo do rótulo.
value input any undefined Valor associado emitido no evento change.
change output SwitchChangeEvent — Evento disparado na alternância emitindo { checked, value }.
