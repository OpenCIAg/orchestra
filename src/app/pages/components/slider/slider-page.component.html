Documentação da API

<orc-slider> (SliderComponent)

Propriedade / input / output Tipo Padrão Descrição
value model<number | [number, number]> 0 Valor atual ou intervalo numérico (Two-Way Binding [(value)]).
range boolean false Habilita o modo de intervalo com dois botões deslizantes (Dual Thumb).
min number 0 Valor mínimo da escala do controle.
max number 100 Valor máximo da escala do controle.
step number 1 Granularidade de incremento/decremento de cada salto.
size 'sm' | 'md' | 'lg' 'md' Tamanho da barra: sm (10px), md (16px - padrão Figma), lg (20px).
showTicks boolean false Renderiza pontos marcadores visuais ao longo da barra em cada passo (step).
showLabels boolean false Exibe rótulos numéricos padrão nas extremidades (mínimo e máximo).
marks Record<number, string> | SliderMark[] | number[] undefined Objeto ou array de marcações e textos personalizados ao longo da barra.
showTooltip 'auto' | 'always' | 'never' 'auto' Comportamento do tooltip flutuante sobre o thumb (auto: hover, focus e arraste).
valueFormatter (val: number) => string undefined Função customizada para formatar a exibição do valor no tooltip e cabeçalho.
label string '' Rótulo descritivo superior associado semanticamente ao slider.
helperText string '' Texto de instrução ou ajuda exibido abaixo do slider.
disabled boolean false Desativa o controle e impede interações por mouse, touch ou teclado.
sliderChange output<number | [number, number]> - Disparado ao finalizar o arraste ou soltar o botão do mouse.
sliderInput output<number | [number, number]> - Disparado em tempo real continuamente durante o arraste do cursor.

Exemplos de código

Exemplo de uso com Angular Standalone & Reactive Forms
import { Component } from '@angular/core';
import { ReactiveFormsModule, FormControl, FormGroup } from '@angular/forms';
import { SliderComponent } from '@orc/ds';

@Component({
  standalone: true,
  imports: [ReactiveFormsModule, SliderComponent],
  template: `
    <form [formGroup]="filterForm">
      <!-- Slider de Valor Único -->
      <orc-slider
        formControlName="volume"
        label="Volume"
        [min]="0"
        [max]="100"
        [step]="5"
        showTooltip="auto"
      />

      <!-- Slider de Faixa de Preço (Dual Range) -->
      <orc-slider
        formControlName="priceRange"
        label="Faixa de Preço"
        [range]="true"
        [min]="0"
        [max]="1000"
        [step]="50"
        [valueFormatter]="formatCurrency"
      />
    </form>
  `
})
export class FiltroProdutosComponent {
  filterForm = new FormGroup({
    volume: new FormControl(70),
    priceRange: new FormControl<[number, number]>([100, 500]),
  });

  formatCurrency(val: number): string {
    return 'R$ ' + val.toLocaleString('pt-BR');
  }
}
