Avatar

Representação visual de usuários, equipes e entidades com suporte a fotos, fallback automático para iniciais ou ícone padrão, indicador de status em tempo real, múltiplos formatos e empilhamento em grupo com contador excedente.

Exemplos de código

1. Uso individual com imagem e status
<!-- Avatar com foto e indicador de status online -->
<app-avatar
  src="https://exemplo.com/foto.jpg"
  name="Juliana Lima"
  status="online"
  size="lg"
/>

<!-- Formato arredondado com fallback automático para iniciais -->
<app-avatar
  name="Bruno Ramos"
  shape="rounded"
  size="md"
/>
2. Grupo de avatares com sobreposição e contador excedente
<!-- Grupo automático com lista e contador excedente -->
<app-avatar-group
  size="md"
  [items]="teamMembers"
  [max]="4"
/>

<!-- Grupo via projeção de conteúdo manual -->
<app-avatar-group size="md">
  <app-avatar initials="AS" colorVariant="primary" />
  <app-avatar initials="CL" colorVariant="royal" />
  <app-avatar initials="MS" colorVariant="orange" />
  <app-avatar initials="+5" colorVariant="default" />
</app-avatar-group>

Referência de API (inputs e outputs)

Propriedade Tipo Padrão Descrição
src input string '' URL da foto do usuário. Se falhar ou não for informada, faz fallback para iniciais.
name input string '' Nome completo usado para extrair iniciais e acessibilidade aria-label.
initials input string '' Texto explícito de iniciais (ex: 'AS', 'CL', '+5').
size input 'xs' | 'sm' | 'md' | 'lg' | 'xl' 'md' Dimensões: xs (24px), sm (32px), md (40px), lg (48px), xl (64px).
shape input 'circular' | 'rounded' | 'square' 'circular' Formato geométrico do avatar.
status input 'online' | 'offline' | 'busy' | 'away' undefined Indicador de status do usuário exibido no canto do avatar.
colorVariant input 'default' | 'primary' | 'royal' | 'orange' | 'purple' | 'auto' 'default' Cor de fundo para iniciais (baseada nas cores da marca Orchestra).
bordered input boolean false Aplica borda branca de separação para sobreposições.
imageError output Event — Disparado caso a URL da imagem não consiga ser carregada.
