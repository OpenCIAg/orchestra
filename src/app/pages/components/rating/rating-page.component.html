Integração nativa com ReactiveFormsModule e nova API de Signals (ControlValueAccessor e Model).

Propriedade Tipo Padrão Descrição
max input number 5 Número máximo de itens na avaliação (estrelas/botões).
allowHalf input boolean false Permite seleção de frações (0.5), ativando detecção de hover por metade do ícone.
numeric input boolean false Altera o layout visual para botões numéricos (Estilo NPS) no lugar de ícones.
clearable input boolean false Permite que o usuário zere a nota ao clicar novamente na mesma pontuação.
readonly input boolean false Trava o estado apenas para exibição (aceita preenchimento fracionado exato).
disabled input boolean false Desabilita o componente inteiro (compatível com form.disable() nativo).
tooltips input string[] [] Array de rótulos exibidos em um Tooltip nativo da biblioteca sobre cada item.
customIcon ContentChild ng-template Estrela Padrão Substitui o ícone de SVG por um customizado pelo desenvolvedor via ng-template.
