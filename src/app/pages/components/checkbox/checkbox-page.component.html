Checkbox

Controle de seleção binária ou intermediária (tri-state/indeterminate) com suporte nativo a formulários reativos, Signals API (`model()`, `input()`, `output()`), estados visuais completos e total acessibilidade WCAG 2.1 AA.

Exemplos de código

1. Uso básico com two-way model signal
<!-- Two-way binding com Signals -->
<app-checkbox [(checked)]="lembrarMe" label="Lembrar meu acesso" />

<!-- Com helper text / descrição -->
<app-checkbox
  [(checked)]="notificacoes"
  label="Ativar notificações push"
  description="Você receberá alertas instantâneos de novas mensagens"
/>
2. Formulários reativos com ControlValueAccessor
<app-checkbox
  formControlName="termos"
  label="Aceito os termos e condições"
  [error]="form.get('termos')?.invalid && form.get('termos')?.touched"
  errorMessage="O aceite dos termos é obrigatório"
/>
3. Estado indeterminado (tri-state / misto)
<app-checkbox
  [checked]="allSelected()"
  [indeterminate]="someSelected()"
  label="Selecionar todos"
  (change)="toggleAll()"
/>

Referência de API (inputs, models e outputs)

Propriedade Tipo Padrão Descrição
checked model boolean false Estado de marcação do checkbox. Suporta two-way binding [(checked)].
indeterminate model boolean false Estado intermediário/misto. Aplica ícone de traço e aria-checked="mixed".
label input string '' Texto do rótulo associado ao checkbox com clique integrado.
description input string '' Texto de apoio ou orientação exibido abaixo do rótulo.
disabled input boolean false Desabilita a interação com o checkbox e aplica estilos atenuados.
error input boolean false Ativa o estado visual de erro e aria-invalid="true".
errorMessage input string '' Mensagem de validação de erro exibida abaixo do rótulo.
value input any undefined Valor/payload associado ao item emitido no evento change.
change output CheckboxChangeEvent — Evento disparado na alteração emitindo { checked, indeterminate, value }.
