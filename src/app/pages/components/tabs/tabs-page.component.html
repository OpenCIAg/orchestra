Referência de API

<app-tab-group>

Propriedade Tipo Padrão Descrição
selectedIndex model number 0 Índice zero-based da aba ativa (two-way binding via Signals).
variant input 'line' | 'filled' 'line' Estilo visual das abas (linha inferior ou formato pílula preenchida).
size input 'sm' | 'md' | 'lg' 'md' Dimensão das abas (36px, 44px ou 52px).
fullWidth input boolean false Se verdadeiro, estende as abas igualmente por toda a largura.
tabChange output TabChangeEvent — Evento emitido quando o usuário troca de aba.

<app-tab>

Propriedade Tipo Padrão Descrição
label input string '' Texto do rótulo da aba.
icon input string '' Ícone SVG exibido junto ao rótulo ('home', 'settings', 'warning', etc.).
iconPosition input 'start' | 'end' 'start' Posicionamento do ícone em relação ao texto da aba.
disabled input boolean false Desabilita a interação e aplica estilo opaco à aba.
badge input string | number undefined Contador ou tag exibida ao lado do rótulo da aba.
