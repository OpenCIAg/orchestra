Referência de API

Propriedade Tipo Padrão Descrição
label input string '' Texto de rótulo acima do campo.
placeholder input string 'Digite e pressione Enter...' Texto de placeholder dentro do input text.
helperText input string '' Texto de instrução secundária abaixo do campo.
errorMessage input string '' Texto de erro de validação. Coloca o componente em estado inválido.
disabled input boolean false Desabilita o input, botões de remover e o dropdown.
readonly input boolean false Torna o campo apenas leitura (impede edição e digitação).
size input 'sm' | 'md' | 'lg' 'md' Tamanho geral do campo, refletindo também no tamanho das tags internas.
allowDuplicates input boolean false Permite inserir strings exatas que já estão na lista de valores.
maxChips input number | undefined undefined Limita a quantidade máxima de tags que podem ser inseridas.
separatorKeyCodes input string[] ['Enter', ',', ' '] Lista de teclas (`event.key`) que confirmam a conversão do texto em um novo chip.
suggestions input string[] [] Lista para autocompletar que surge abaixo do input quando o usuário digita.
chipsChange output output<string[]> - Dispara os valores sempre que a lista de chips for alterada.
maxReached output output<void> - Dispara um evento quando o usuário tenta inserir além do `maxChips`.
