Como usar

Use a estrutura modular de tags projetadas para montar diferentes layouts de cards.

Importação

import {{ '{' }} CardComponent, CardHeaderComponent, CardBodyComponent, CardFooterComponent {{ '}' }} from 'src/app/shared/card';

@Component({{ '{' }}
  imports: [
    CardComponent,
    CardHeaderComponent,
    CardBodyComponent,
    CardFooterComponent
  ],
{{ '}' }})
export class SeuComponente {{ '{' }}{{ '}' }}

Template HTML (Card Simples)

<app-card>
  <app-card-header>
    <strong>Título do Card</strong>
  </app-card-header>
  <app-card-body>
    <p>Conteúdo principal do seu card.</p>
  </app-card-body>
  <app-card-footer>
    <button>Ação</button>
  </app-card-footer>
</app-card>
