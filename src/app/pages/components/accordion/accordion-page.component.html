Design do Figma (lista completa)

Um Design System é uma coleção de componentes reutilizáveis, guiados por padrões claros, que podem ser combinados para construir qualquer número de aplicações de forma consistente e eficiente. Garante que diferentes produtos e telas mantenham o mesmo tom, identidade visual e usabilidade previsível para o usuário final. Comece documentando tokens básicos (cores, tipografia, espaçamentos), construa componentes atômicos e estabeleça uma cultura colaborativa em equipes de design. Aceleram o tempo de entrega, reduzem retrabalho e facilitam correções e atualizações globais em escala. Promove a integração contínua entre designers e desenvolvedores, garantindo fidelidade de layout e código padronizado.

Customização com projeção de cabeçalho (ng-content)

Avançado Notificações e alertas por e-mail
Você pode projetar qualquer elemento personalizado dentro do cabeçalho utilizando o seletor [accordion-header], incluindo badges, ícones personalizados e switches.
Segurança Autenticação em dois fatores (2FA)
Proteja sua conta com verificação em duas etapas via aplicativo autenticador ou SMS.

Exemplos de código

1. Uso padrão exclusivo (um item por vez)
<app-accordion>
  <app-accordion-item title="O que é um Design System?" [expanded]="true">
    Um Design System é uma coleção de componentes reutilizáveis...
  </app-accordion-item>

  <app-accordion-item title="A importância da consistência no design.">
    Garante que diferentes produtos e telas mantenham o mesmo tom...
  </app-accordion-item>
</app-accordion>
2. Modo múltiplos itens abertos simultaneamente
<app-accordion [multiple]="true" variant="separated">
  <app-accordion-item title="Primeiro item" [(expanded)]="item1Open">
    Conteúdo 1
  </app-accordion-item>

  <app-accordion-item title="Segundo item" [(expanded)]="item2Open">
    Conteúdo 2
  </app-accordion-item>
</app-accordion>

Referência de API

AccordionComponent (Pai)

Propriedade Tipo Padrão Descrição
multiple input boolean false Permite que mais de um item permaneça expandido simultaneamente.
variant input 'default' | 'separated' | 'bordered' 'default' Estilo visual do container do accordion.
expandedChange output AccordionToggleEvent — Disparado quando qualquer item tem seu estado alterado.

AccordionItemComponent (Filho)

Propriedade Tipo Padrão Descrição
title input string '' Título padrão exibido no cabeçalho.
expanded model boolean false Estado de expansão com suporte a two-way binding [(expanded)].
disabled input boolean false Desabilita a interação com o cabeçalho do item.
subtitle input string '' Subtítulo secundário opcional.
opened output void — Disparado quando o item é expandido.
closed output void — Disparado quando o item é colapsado.
