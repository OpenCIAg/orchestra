OTP Input

Campos de entrada de código de uso único (One-Time Password) modulares e acessíveis, com suporte nativo a Reactive Forms, Signals API, navegação automática de foco, suporte a colagem de SMS/clipboard e arquitetura composta (Compound Components).

Referência da API

app-otp-input (Componente principal)

Propriedade Tipo Padrão Descrição
length input<number> 6 Quantidade total de dígitos/slots do OTP.
value model<string> '' Valor completo do código com suporte a Two-Way Binding ([(value)]) e Reactive Forms.
inputMode input<'numeric' | 'text'> 'numeric' Tipo de teclado acionado em dispositivos móveis.
placeholder input<string> '' Caractere indicador exibido nos slots vazios.
disabled input<boolean> false Desabilita a interação com todos os campos.
ariaLabel input<string> 'Código de verificação' Rótulo de acessibilidade anunciado para cada slot por leitores de tela.
completed output<string> - Disparado quando todos os dígitos do código são preenchidos.
