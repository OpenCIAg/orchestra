# Core/display/navigation ledger revalidation

Revalidated 2026-09-13 against the source and focused specs available at that point. This review covers Accordion, Breadcrumb, Card, Carousel, Divider, EmptyState, Image, List, NavigationShell/Item, ProgressBar/Circle/Spinner/LoadingSpinner/Skeleton, ScrollArea, Stepper, TabGroup/Tab, Timeline/Toolbar, and Tag. Table, Paginator, TabMenu, and TreeView were intentionally excluded. This is a dated audit snapshot; the 2026-09-22 repairs below supersede several findings. No tests were run during the original revalidation.

The status below separates a false or stale source claim from a real implementation gap and from behavior that exists but has no direct focused test. `all-components-lifecycle.spec.ts` is treated as instantiation/teardown evidence only.

The table is a frozen 2026-09-13 snapshot, not the current open-defect list. Some rows intentionally describe behavior that was broken at that date; use the 2026-09-22 superseding repairs and linked current ledgers below for today's status. The current open gaps are the ones explicitly retained in those later notes.

## Superseding repairs as of 2026-09-22

- **Card:** the former clickable article key handlers were replaced with a native, visually full-card primary button. `clickable` and `selected` coerce boolean attributes; `Space` activation and default suppression now come from native button behavior. Focused DOM tests cover the accessible name, selected state, geometry, keyboard activation, one-time events, and independent nested controls in [`card.component.spec.ts`](../../../projects/orc-ds/card/card.component.spec.ts). Card is no longer in the P0 repair list below.
- **EmptyState:** the region now has a fallback name (overridden by `ariaLabel` or its title), optional visible heading/description, and a separately named action. Blank action labels do not render or emit; [`empty-state.component.spec.ts`](../../../projects/orc-ds/empty-state/empty-state.component.spec.ts) covers the named-region and action contracts.
- **Carousel and navigation:** the Carousel `activeIndex`/`page` repair and direct coverage for Breadcrumb, List, NavigationShell, ScrollArea, Timeline, and Toolbar were originally cited to `audit-display-docs.md`, a defective duplicate of the expansion audit since removed; those records live in the [behavior coverage ledger](../behavior-coverage-ledger.md). [`navigation-state-audit.md`](navigation-state-audit.md) records the TabGroup and Stepper alias repairs. Findings in the table above for these areas describe only the 2026-09-13 snapshot.
- **Progress and loading display:** the ProgressBar name/value/marker/reduced-motion repairs and LoadingSpinner static/reduced-motion/live-region behavior were originally cited to the removed defective `audit-display-docs.md` duplicate; those records live in the [behavior coverage ledger](../behavior-coverage-ledger.md). Skeletons are decorative by default and announce only when `ariaLabel` is supplied. ProgressCircle still needs broader focused visual review; do not generalize the ProgressBar result to every progress control.
- **Tag:** secondary and contrast variants now have semantic light/dark colors, removable controls have a useful fallback name and visible focus, and both removal outputs plus disabled behavior are covered in [`tag-behavior.spec.ts`](../../../projects/orc-ds/tag/tag-behavior.spec.ts).
- **Latest integrated verification:** the enterprise component follow-up passes 1461/1461 library tests under both seeds, 33/33 Chromium/Firefox/WebKit interactions, 82/82 docs tests, all three production builds, current/minimum packed package checks, compatibility, themes, documentation integrity, formatting, diff checks, and SSR render/teardown for all 147 components. See [`enterprise-audit.md`](../enterprise-audit.md) and the [current gate](../verification/enterprise-component-followup-20260924/gate-summary.md).

## Prioritized repair batches

1. **P0 interaction and naming:** Image preview focus and naming now include recovery to a stable container when the trigger disappears, with all 27 inputs and five outputs classified. NavigationShell native controls, ProgressBar defaults, LoadingSpinner motion, and Card primary-action semantics also have direct coverage. Continue with remaining EmptyState, ProgressCircle, Skeleton, Tag, and Image device/assistive-technology combinations.
2. **P1 state and control semantics:** define one source of truth for Carousel `activeIndex`/`page`, Stepper `currentStep`/`activeIndex`, and TabGroup `value`/`selectedIndex`; remove nested Tab close interactivity or move it outside the tab button; implement Accordion item options that are currently inert; add controlled-update tests.
3. **P1 overlays and motion:** reset Image fallback/error state on source changes; implement preview focus behavior; fix LoadingSpinner static mode; add reduced-motion rules for determinate/indeterminate progress and a concrete marker announcement contract.
4. **P2 navigation/display coverage:** add focused DOM specs for Breadcrumb, Divider, List, Navigation, ScrollArea, Timeline, Toolbar, and the untested Card/Image/Stepper/Tab paths. Include disabled indexing, dynamic item changes, resize measurement, both-axis paging, focus movement, and event payload assertions.
