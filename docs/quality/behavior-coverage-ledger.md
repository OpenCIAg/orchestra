# Behavior coverage ledger

Reset for `22.4.0-rc.0` (onda A1): rows for the families, directives and services removed by [`docs/overhaul/DECISOES.md`](../overhaul/DECISOES.md) were dropped, links to deleted specs were unlinked, and the historical gate narrative of the compatibility period was retired (it remains in git history). The behavior evidence of each surviving family is rewritten by its wave-B executor.

The ledger distinguishes behavior evidence from inventory references:

- **Behavior** means a focused spec asserts interaction, state, CVA, event, keyboard, focus, overlay, or observable DOM behavior.
- **Behavior (narrow)** means a broad family spec or a small edge-path assertion provides some behavior evidence, while major contracts remain uncovered.
- **Render/lifecycle only** means the class is mounted by all-components-lifecycle.spec.ts or has no focused behavior assertion. That suite is evidence of instantiation/teardown only and is not counted as interaction coverage.
- A passing compile or global smoke run is not behavior evidence. The linked family specs are evidence references; the defect index below records source-backed gaps.
- A source/spec reference is not complete behavior coverage: it records what was inspected or asserted, not every public input or integration contract. Directives and services require their own ledger before the library can be called fully covered.

Current rollup: **136 Behavior, 11 Behavior (narrow), 0 Render/lifecycle only** (147 components). Every inventoried component now has focused behavior evidence or a direct family contract; the narrow tier marks deliberately bounded coverage rather than exhaustive public-input coverage. PanelMenu's contract and the Menubar keyboard/ARIA contract are included in the sealed freeze-20 integrated evidence. The CascadeSelect docs route and controlled leaf-selection preview are covered by the freeze-21 docs tests and desktop browser QA.
