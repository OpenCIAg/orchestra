The ledger distinguishes behavior evidence from inventory references:

- **Behavior** means a focused spec asserts interaction, state, CVA, event, keyboard, focus, overlay, or observable DOM behavior.
- **Behavior (narrow)** means a broad family spec or a small alias/edge-path assertion provides some behavior evidence, while major contracts remain uncovered.
- **Render/lifecycle only** means the class is mounted by all-components-lifecycle.spec.ts or has no focused behavior assertion. That suite is evidence of instantiation/teardown only and is not counted as interaction coverage.
- A passing compile or global smoke run is not behavior evidence. The linked family specs are evidence references; the defect index below records source-backed gaps.
- A source/spec reference is not complete behavior coverage: it records what was inspected or asserted, not every public input or integration contract. Directives and services require their own ledger before the library can be called fully covered.
