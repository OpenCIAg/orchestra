# P2 module separation and interaction follow-up — 2026-09-23

**PASS.** The Splitter, Portal, and DataTable implementations now live in focused modules while their established P2, legacy, facade, and packed secondary import paths preserve class/type identity. Splitter resizes by pointer drag with keyboard support, and ContextMenu now handles outside interaction, coordinates, and keyboard focus across same-origin iframe targets. PickList preserves destination focus after transfers at a 320px viewport; OrderList handles numeric zero as a valid option value for focus and selection. The full library suite passes **1337/1337** under Jasmine seeds `4321` and `20260923`.

Splitter's `onPointerResizeEnd` reports pointer-up or pointer-cancel while the existing keyboard `onResizeEnd` output remains unchanged. ContextMenu listens for outside mousedown in both its host document and a direct target's owner document. Same-origin frame coordinates are mapped into the host viewport using frame bounds, borders, and scaling. Opening a menu focuses its active item; Escape and activation restore focus to the invoking control, while outside dismissal leaves focus with the new target.

Portal now has its own focused implementation module and shares `isElementTarget` through `p2-dom-target.ts` with ContextMenu. The former overlay module remains an identity-preserving compatibility export, the docs facade imports the focused module, and Portal's `portal` secondary entry is identity-checked in packed consumers.
