# Enterprise component contract follow-up — updated 2026-09-24

**PASS for the verified repository gates.** This follow-up adds focused interaction coverage and repairs for accessibility, form state, overlays, lifecycle, keyboard behavior, and scroll ownership. The complete library suite passes **1390/1390** under Jasmine seeds `4321` and `20260923`; a curated rerun of repaired component families passes **108/108** with runtime diagnostics enabled. DateTime outside dismissal, declarative Modal dismissal policies, Modal focus containment/restoration, Tooltip hover cleanup, Button icon spacing, and TagsInput Tab focus traversal pass **21/21** browser checks across Chromium, Firefox, and WebKit.

## Findings and repairs

- Blank/whitespace-only accessible-name overrides now fall back to useful labels in Form and Kbd. Form spacing consumes the shared spacing token.
- Readonly Switch remains focusable and announced while rejecting activation; whitespace-only accessible-name overrides fall back to its visible label. Tree selection propagation skips disabled parents, preserves empty-string keys, and consistently guards its declared events.
- Destroying an open Popover restores focus to a surviving opener. Inplace prefers projected display content, supplies an accessible close label, and ignores Escape while IME composition is active; the public bug fix is recorded in a patch Changeset.
- BlockUI now lives in a focused module, while the old P2 and secondary entry points preserve class/type identity. Chart has a discoverable docs route that demonstrates the four rendered types and labels its four status-only compatibility values.
- ConfirmDialog, ConfirmationService, and `ConfirmationRequest` now live in a focused P2 module. Legacy, P2, and secondary exports retain runtime identity and request-type usability.
- ScrollTop listens only to its active scroll surface, rebinds and cleans up when the target changes, respects reduced motion, retains focus until blur, treats offset zero as authoritative, and resolves whitespace-only labels.
- Dropdown keeps its action menu flat: the legacy `DropdownItem.children` field is deprecated and ignored, while the owning row still emits and runs its action. TieredMenu is the supported hierarchy component.
- TagsInput paste tokenizes configured separators, filters duplicates and limits, and emits one CVA update. Its `addOnTab` commits a draft without cancelling native Tab focus navigation. ChipInput blur ordering and IME behavior are covered. OTP numeric entry and arrow navigation are covered. TreeSelect ignores queued blur/touched work after destruction, removing an Angular NG0953 warning.
- Tree’s **18/18** direct contracts now verify subscribers observe committed expansion state and disabled branches cannot expand by button or direct method call. Tree and Chart focused contracts also cover their declared selection/output and presentation behavior more completely. Portal’s projected child component is tested across movement and destruction; no Portal implementation change was needed.
- FormField now applies error borders through the theme alias actually consumed by projected controls, uses a block wrapper that supports textareas, and updates label/required/error/helper relationships live. Terminal and Kbd cover whitespace labels, command-history autoscroll, and multiword key parsing; Terminal is now discoverable in the docs catalog.
- Modal returns focus to its pointer opener in WebKit when the browser reports `body` as active during a click; browser checks cover initial focus, Tab/Shift+Tab containment, Escape dismissal, and focus restoration. Tooltip hover/exit cleanup is checked in all three engines. Inplace remains unit-tested because the docs app has no example route for it.
- Authored library TypeScript, templates, stylesheets, and entry-point JSON manifests now follow Prettier; the generated Material Symbols catalog and manifest keep their generator-owned formatting. CI enforces authored library style with `npm run format:check`.

No whole component is identified as useless from this repository. `OverlayComponent` still provides a live visibility primitive despite deprecated no-op positioning inputs. `TooltipComponent`, the one-line `TextInputComponent`/`ToggleComponent` aliases, and compatibility path aliases are major-release simplification candidates only after external consumer usage and semver impact are reviewed; current evidence does not justify removal.
