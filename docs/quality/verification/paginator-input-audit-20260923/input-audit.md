# Paginator input audit

The public declaration inventory contains **44 input/model entries**. The audit traced each entry from its Angular declaration through `projects/orc-ds/paginator/paginator.component.html` and component runtime. **39 are behavior-tested supported inputs/models** and **5 remain accepted as explicitly deprecated compatibility no-ops**. There are no unverified inputs in this pass.

The supported surface keeps native buttons, `<select>`, and number input controls. It preserves inline layout and the existing 768px responsive stack. No overlay, arbitrary template injection, or browser-owned popup behavior is implied by the component API.

## Changes and limitations

The focused behavior spec now asserts total precedence, page-size option precedence/fallback, page-link alias, report visibility, page-link visibility, first/last icon alias, navigation button visibility, selector hiding, root style/class, and size class. The paginator runtime had no additional concrete defect exposed by this input pass. The unused `PaginatorVariant` import was removed; the exported `PaginatorVariant` type remains unchanged for import compatibility.

The normal `ng test orc-ds` compilation currently encounters unrelated TypeScript errors in `projects/orc-ds/multi-select-contract.spec.ts` and `projects/orc-ds/p2/listbox-behavior.spec.ts`. The paginator suite was therefore compiled and run with an isolated spec tsconfig; see [focused test evidence](./focused-test-evidence.md). This does not establish that the full library suite passes.
