# Select input audit — 2026-09-23

`SelectComponent` declares 78 inputs/models at [select.component.ts](../../../../projects/orc-ds/select/select.component.ts#L93). The audit found 60 supported inputs and 18 compatibility no-ops. Every supported input has direct behavior coverage across `select-repair.spec.ts` and `select-input-contract.spec.ts`; the combined focused run passes 31/31. No live input remains wired-but-unasserted.

The 60 behavior-tested inputs are: `id`, `name`, `placeholder`, `label`, `helperText`, `errorMessage`, `status`, `multiple`, `searchable`, `searchPlaceholder`, `searchEmptyText`, `disabled`, `readonly`, `required`, `clearable`, `options`, `optionLabel`, `optionValue`, `optionDisabled`, `filter`, `filterPlaceholder`, `filterLocale`, `filterBy`, `filterFields`, `filterMatchMode`, `emptyFilterMessage`, `emptyMessage`, `showClear`, `inputId`, `style`, `styleClass`, `panelStyle`, `panelStyleClass`, `appendTo`, `tabindex`, `variant`, `size`, `fluid`, `loading`, `loadingIcon`, `loadingMessage`, `autofocus`, `dropdownIcon`, `lazy`, `virtualScroll`, `dataKey`, `autoZIndex`, `baseZIndex`, `focusOnHover`, `autoOptionFocus`, `maxlength`, `resetFilterOnHide`, `scrollHeight`, `ariaLabel`, `ariaLabelledBy`, `ariaFilterLabel`, `clearAriaLabel`, `removeOptionAriaLabel`, `ariaDescribedby`, and `value`.

The 18 explicitly deprecated compatibility no-ops are: `overlayOptions`, `autofocusFilter`, `editable`, `checkmark`, `optionGroupLabel`, `optionGroupChildren`, `autoDisplayFirst`, `group`, `virtualScrollItemSize`, `virtualScrollOptions`, `itemSize`, `selectOnFocus`, `showTransitionOptions`, `hideTransitionOptions`, `tooltip`, `tooltipPosition`, `tooltipPositionStyle`, and `tooltipStyleClass`.

`lazy` and `virtualScroll` emit the initial `{ first, last }` range when the panel opens. They do not implement incremental loading or a virtual viewport. The `name` input now contributes native hidden form fields; multiple selections serialize one field per selected value, disabled controls are omitted from `FormData`, and readonly controls remain submittable. Whitespace-only trigger/filter/clear/removal labels use useful accessible-name fallbacks; nonblank overrides are trimmed.

Cross-input combinations, physical-device behavior, other browsers, and assistive-technology announcement timing remain unverified.
