# Calendar input and behavior audit

This audit reconciles the 23 public input names in `docs/quality/inventory.json` with `CalendarComponent` in `projects/orc-ds/p2/p2-calendar-component.ts`. The direct contract suite is `projects/orc-ds/p2-date-input-contract.spec.ts`; it also contains the adjacent DateInput contracts. The Calendar surface has two model inputs and 21 signal inputs. Outputs include the generated `valueChange` and `currentMonthChange` model events, plus `dateSelected`, `onSelect`, `onClear`, and `onTodayClick`.

| Public input         | Kind   | Status and observable evidence                                                                                                                                                                                                              |
| -------------------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `value`              | model  | Active. Date-only and date-time CVA normalization, parent-bound time synchronization, scalar/array selection, and the `valueChange` payload are asserted. Multiple/range modes preserve an initial scalar as their first selected value.    |
| `currentMonth`       | model  | Active `yyyy-MM` model. Month navigation updates the controlled host through `currentMonthChange`; keyboard month crossing and Today update the displayed month.                                                                            |
| `min`                | signal | Active ISO date boundary; the day before the minimum is disabled and the minimum date remains selectable.                                                                                                                                   |
| `max`                | signal | Active ISO date boundary; the maximum remains selectable and the next date is disabled.                                                                                                                                                     |
| `disabled`           | signal | Active. Day/time/header/footer controls disable and stale direct selection, clear, Today, and month navigation do not mutate state.                                                                                                         |
| `inputId`            | signal | Active. Supplies the calendar grid ID as `${inputId}-grid`; an instance ID is generated when omitted.                                                                                                                                       |
| `styleClass`         | signal | Active. Appended to the root section class list.                                                                                                                                                                                            |
| `style`              | signal | Active. Passed to the root inline style; the contract asserts a custom width.                                                                                                                                                               |
| `ariaLabel`          | signal | Active. Names the calendar section. The grid separately uses its localized month/year as its accessible name.                                                                                                                               |
| `locale`             | signal | Active. Formats month and weekday names and reads the locale’s week start from `Intl.Locale.getWeekInfo()` or `weekInfo`; older runtimes use a regional fallback (Monday by default). The French contract asserts Monday-first alignment.   |
| `previousMonthLabel` | signal | Active. Sets the previous-month button’s accessible name; falls back to “Previous month”.                                                                                                                                                   |
| `nextMonthLabel`     | signal | Active. Sets the next-month button’s accessible name; falls back to “Next month”.                                                                                                                                                           |
| `todayLabel`         | signal | Active. Adds the Today action when the button bar is enabled; the action jumps from another month and emits the selected date.                                                                                                              |
| `clearLabel`         | signal | Active. Adds the Clear action when the button bar is enabled; clear updates the model/CVA and emits `onClear`.                                                                                                                              |
| `inline`             | signal | Deprecated compatibility no-op. The component always renders inline; the separate DatePicker owns popup behavior. A test confirms `inline=false` still renders the inline calendar.                                                         |
| `showTime`           | signal | Active. Shows the native time editor and selects/normalizes `yyyy-MM-ddTHH:mm` values; valid edits update the CVA and `onSelect`.                                                                                                           |
| `dateFormat`         | signal | Deprecated compatibility no-op. Calendar values and outputs consistently use ISO strings; formatting is not a display-format input for this string-valued implementation. A test confirms a non-ISO format does not change selected values. |
| `showButtonBar`      | signal | Active. Controls whether the configured Today/Clear actions are rendered.                                                                                                                                                                   |
| `selectionMode`      | signal | Active: single emits a string, multiple toggles an array, and range orders its two endpoints. Focused tests observe the rendered selection and output payloads.                                                                             |
| `disabledDates`      | signal | Active. Date objects are compared by local calendar date; the matching date cannot be activated, including through a stale direct day argument.                                                                                             |
| `disabledDays`       | signal | Active; uses JavaScript weekday numbers (Sunday `0` through Saturday `6`). A configured weekday is disabled and keyboard navigation skips disabled dates.                                                                                   |
| `showOtherMonths`    | signal | Active. Hides adjacent-month date buttons while retaining blank grid cells so weekday columns stay aligned.                                                                                                                                 |
| `selectOtherMonths`  | signal | Active. Enables adjacent-month dates only when shown; selecting one updates both the selected value and displayed month. Stale day objects are rejected after the option is turned off.                                                     |

The calendar grid now has explicit weekday/header and week rows, one roving day tab stop, and Arrow, Home/End, and Page Up/Down navigation. Navigation skips disabled dates, crosses month boundaries, and clamps month/year jumps to the destination month’s last day. Header buttons have descriptive accessible names by default and are disabled with the control. Focus leaving the whole Calendar marks the CVA touched; moving focus among its internal controls does not.

`writeValue` remains silent, while user selection/time edits/clear invoke the registered change callback. Selection, time editing, and clear invoke the touched callback; focus leaving the composite also marks it touched. The output contracts preserve payloads: `dateSelected` emits the ISO date/string for a day selection, `onSelect` emits `{ value }`, `onClear` emits no payload, and `onTodayClick` emits the ISO day. Using Today on an already-selected multiple date is idempotent and does not toggle that value off.

## Verification

Focused suite: **16/16 passed** in Chrome Headless 153 on Node 24.16 (15 Calendar contracts and one adjacent DateInput contract). The French locale assertions verify Monday-first weekday labels and February 2025 date placement after the locale fallback fix. The package library build, Prettier, and `git diff --check` passed for the final Calendar changes.

Limitations: verification is DOM-based in ChromeHeadless; no manual screen-reader, touch, RTL, or cross-browser layout pass was run. Runtimes without `Intl.Locale.getWeekInfo()` and `weekInfo` use a regional fallback with a Monday default, which does not replace the full CLDR week-data set. Navigation labels fall back to English unless callers supply the label inputs, and the time input’s visible label is currently the fixed English word “Time”. `min`/`max` are interpreted as ISO date prefixes; this component does not implement timezone-aware instants or arbitrary date-format parsing.
