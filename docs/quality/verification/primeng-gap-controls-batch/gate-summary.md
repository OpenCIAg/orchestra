# PrimeNG gap controls contract batch

The focused Chrome Headless suite passed **8/8** with the browser runtime-diagnostics harness included. It ran on Node 24.16.0 with `NG_BUILD_MAX_WORKERS=2` and Karma port 9884. Full output is in [focused-tests.log](focused-tests.log).

The contracts cover Fluid wrapper classes and spacing; OverlayBadge zero and decorative-dot accessibility; Password label/id, required semantics, reactive-form value/touched/disabled behavior, visibility and clear state, readonly protection, style variants, sizes, and strength feedback; and SplitButton accessible menu state, arrow/Home/End keyboard navigation, Escape with focus restoration, Escape opt-out, outside dismissal, action activation, icon position, tooltip, severity, size, and loading state.

The fixes make `0` render as a numeric badge, add an accessible label option for badges, and use logical inline positioning. Password now generates an associated input id when needed, binds native `required`, retains its base CSS classes alongside caller classes, applies its variant/size/fluid inputs, lays out the control and feedback correctly, prevents clearing readonly or form-disabled values, and marks accepted clear actions as touched through CVA. SplitButton now gives its controls/menu accessible semantics, supports keyboard navigation and focus restoration, closes on outside pointer/focus exit, respects disabled/loading items, applies icon/tooltip/size/severity inputs, and preserves its menu classes. The follow-up Password evidence is in [password-contract-batch](../password-contract-batch/gate-summary.md).

Three declared inputs remain no-ops because these controls do not currently render a movable or animated overlay: Password `appendTo`, `showTransitionOptions`, and `hideTransitionOptions`; SplitButton `appendTo`. SplitButton built-in severity styling currently maps `secondary`, `success`, `info`, `warning`/`warn`, and `danger`; other strings remain available as classes for caller CSS but have no built-in rule. This batch does not include a full responsive visual/browser matrix or server-render/hydration review.
