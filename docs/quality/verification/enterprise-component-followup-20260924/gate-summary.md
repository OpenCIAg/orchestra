# Enterprise component follow-up — public-input wave, updated 2026-10-01

**PASS for the repository gates listed below.** The full library suite passes **1464/1464** under Jasmine seeds `4321` and `20260923`. The three-browser Playwright matrix passes **36/36** across Chromium, Firefox, and WebKit, including Galleria fullscreen semantics and focus return, Image preview naming, zoom bounds, Escape dismissal, and focus return, plus Calendar keyboard navigation, responsive PickList layout, and desktop drag transfer. The production library/docs/template builds, docs tests, compatibility metadata, packed current/minimum Angular consumers, SSR rendering, theme contracts, documentation integrity, formatting, and diff checks pass.

This checkpoint adds complete public-input audits for Calendar (23), Tree (39), Input (37), Button (31), Dropdown (26), DataView (38), Galleria (31), PickList (31), ProgressBar (22), ProgressCircle (19), Inplace (7), and Image (27), as well as focused contracts for Galleria (20), DataTable (19), EmptyState, and ScrollArea (6). Their focused suites pass **16/16, 21/21, 17/17, 21/21, 13/13, 14/14, 20/20, 6/6, 16/16, 11/11, 20/20, 19/19, and 6/6**, respectively; the ProgressBar/ProgressCircle count is shared, with six direct circle cases. Repairs include ScrollArea viewport bounding-box and scrollbar measurement synchronization, Galleria fullscreen dialog semantics, Escape dismissal, and pointer-opener focus return across engines, DataTable pointer-row keyboard activation and focus outlines, EmptyState text trimming and whitespace fallbacks, locale week-start resolution, disabled Tree branch behavior and loading/empty-state handling, Input zero/mask/caret/keyboard behavior, Button loading icons/icon-only labels/badge styling, Dropdown spec isolation, DataView whitespace and cyclic-record fallbacks, Galleria side-thumbnail layout/scrolling and autoplay behavior, PickList filtering, responsive layout, selection semantics, striping, and drag/drop, plus ProgressBar size, segment bounds, marker normalization, and accessible-name repairs; ProgressCircle now renders meaningful static indeterminate state, applies all styling/animation inputs, accepts numeric size attributes, and trims accessible text; Inplace focus recovery and module extraction are covered. Image now trims label overrides, restores focus across browser engines even when its trigger disappears, and documents three deprecated no-op inputs. Modal now prefers a captured pointer opener when browser focus is stale. API matrices and remaining limits are documented beside the verification artifacts.

No whole component is identified as safe to remove from repository evidence alone; external consumer usage is unknown. Compatibility aliases and other simplification candidates are recorded in [library scope decisions](../../library-scope-decisions.md). The suite and smoke checks are not certification of every component or environment. Physical mobile, assistive-technology, responsive/RTL visual, broader cross-browser, hydration, and external consumer validation remain open.
