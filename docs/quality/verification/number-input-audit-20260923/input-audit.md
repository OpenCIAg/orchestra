The accessible-name regression was concrete: an unlabeled spinbutton had no computed name. The template now supplies a default name only when no visible label, `ariaLabel`, or `ariaLabelledBy` is present. Precision rounding also had a floating-point edge: `2.4 + 0.25` could round to `2.6` at one decimal place. The clamp now uses decimal scaling with an epsilon adjustment; the regression asserts `2.7`.

## Remaining limits

Locale-aware text entry is not covered as broadly as locale display: `handleInput` normalizes a comma heuristically and strips other characters. Grouping/decimal ambiguity across locales, incomplete edit strings, and currency paste behavior need a separate input-parsing contract. Layout modifiers have DOM-class coverage; a browser visual pass across all affix and clear-button combinations remains open.
