# Image public-input audit — 2026-09-24

`ImageComponent` exposes 27 inputs and five outputs. All 24 behavior inputs are covered by direct browser contracts; `appendTo`, `showTransitionOptions`, and `hideTransitionOptions` are retained as deprecated compatibility no-ops and are checked to remain behavior-free. The five outputs (`loaded`, `error`, `onImageError`, `onShow`, and `onHide`) have direct emission or consumer-binding coverage.

| Input                                                                                                         | Classification   | Evidence                                                                                                       |
| ------------------------------------------------------------------------------------------------------------- | ---------------- | -------------------------------------------------------------------------------------------------------------- |
| `src`                                                                                                         | Behavior         | Initial rendering, source replacement, fallback reset, and preview source update.                              |
| `srcSet`, `sizes`                                                                                             | Behavior         | Responsive attributes render and clear while the fallback is active.                                           |
| `previewImageSrc`, `previewImageSrcSet`, `previewImageSizes`                                                  | Behavior         | The preview uses each explicit high-resolution source input; source changes reset zoom and rotation.           |
| `alt`                                                                                                         | Behavior         | Empty alt is preserved for decorative images; preview alt and derived trigger name are asserted.               |
| `fallbackSrc`                                                                                                 | Behavior         | First error selects the fallback; a later source error and source update reset failure state.                  |
| `fit`, `width`, `height`, `loading`, `radius`                                                                 | Behavior         | Object-fit, pixel and CSS dimensions including zero, native loading, and radius class are asserted.            |
| `placeholder`                                                                                                 | Behavior         | Placeholder rendering and explicit/automatic height behavior are asserted.                                     |
| `ariaLabel`                                                                                                   | Behavior         | Whitespace-only values use useful trigger, dialog, and image names.                                            |
| `zoomOutAriaLabel`, `zoomInAriaLabel`, `rotateLeftAriaLabel`, `rotateRightAriaLabel`, `closePreviewAriaLabel` | Behavior         | Custom nonblank and default labels are asserted; zoom bounds and rotation are covered.                         |
| `preview`                                                                                                     | Behavior         | Native button activation, disabled-preview behavior, modal dismissal, focus, and scroll lifecycle are covered. |
| `styleClass`, `imageClass`, `imageStyle`                                                                      | Behavior         | Figure/image class forwarding and image style forwarding are asserted.                                         |
| `appendTo`                                                                                                    | Deprecated no-op | Setting a destination does not move the native dialog.                                                         |
| `showTransitionOptions`, `hideTransitionOptions`                                                              | Deprecated no-op | Supplied durations do not override the modal's fixed transition styling.                                       |

The 20/20 Image-focused browser suite is [image-behavior.spec.ts](../../../../projects/orc-ds/image/image-behavior.spec.ts); its [run log](focused-tests.log) records the current source state. It covers preview focus return when the trigger is removed, including when `preview` is disabled, alongside normal focus restoration, Escape/backdrop close, focus containment, parent-modal ownership, scroll cleanup, and destruction. The shared Modal's stale-active-element regression passes in [23/23 focused tests](modal-focus-tests.log). A real docs-page preview test also passes across Chromium, Firefox, and WebKit in the [33/33 browser matrix](../enterprise-component-followup-20260924/browser-interactions.log).

The no-op inputs stay available for the compatibility window. Remove them only through a major-version migration after checking downstream consumers.
