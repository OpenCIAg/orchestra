# P2 expansion audit

Initial audit: 2026-09-08. Cumulative repairs and verification through 2026-09-23.

Scope of the initial audit: read-only review of every implementation in `projects/orc-ds/p2`, the P2 barrel/package entry points, every secondary entry that re-exports P2, `p2-expansion.spec.ts`, and release compatibility scripts/matrix. Generated icon catalog, binary assets, and dependencies were skipped. Subsequent repair batches changed implementation and test files; the current status is below.

## Release compatibility tooling

`tools/release/verify-compatibility.mjs:5–30` reads `compatibility/versions.json`, selects `RELEASE_BRANCH` or the current branch, checks the library major and four Angular peer ranges, and exits nonzero on mismatch. It does not validate PrimeNG compatibility, Node version, package exports, built artifacts, or that the branch is clean. It also rejects detached HEAD/feature branches unless `RELEASE_BRANCH` is supplied; CI should set it explicitly.

`tools/release/score-compatibility.mjs:4–16` parses only rows whose score is a single digit 0–3 and computes the matrix summary. It does not validate duplicate/missing entry points, malformed scores, source exports, or test evidence. `compatibility/primeng-v19.md:18–131` has 112 rows and reports 269/336 (80.1%), but its scores are editorial assertions; the script cannot detect stale claims.
