# Public binding alias audit

Audited 2026-09-13 against authored `projects/orc-ds/**/*.ts` and the sealed partial-compiled declarations in `dist/orc-ds/fesm2022` (package SHA-256 `a9782e8341b1c9f1650a252d387e6d5b96ff0c61c5a3ba04a9b9035b77dbc910`). The source scan searched for public signal/property assignments such as `readonly alias = this.other`; each result was checked against the component declaration's `inputs` and `outputs` metadata. A TypeScript property alias is available to code using the component class, but Angular does not register it as a host-template binding unless it is itself created with `input`, `output`, or `model` (including an explicit alias option).

## Confirmed registration

The Image repair is registered in the sealed package. `ImageComponent` declares `error = output(...)` and `onImageError = output<Event>({ alias: 'onImageError' })` at `projects/orc-ds/image/image.component.ts:68`; the sealed declaration at `dist/orc-ds/fesm2022/ciag-orchestra-image.mjs:162` contains `outputs: { loaded: 'loaded', error: 'error', onImageError: 'onImageError', onShow: 'onShow', onHide: 'onHide' }`. Its consumer-template test (`projects/orc-ds/image/image-behavior.spec.ts:21-107`) observes one emission through each name, and the live browser fixture used in [Image browser QA](verification/image-card-slider-batch/image-browser-qa.md) loaded the sealed package without console warnings or errors.

Explicit alias declarations elsewhere also register correctly in the sealed metadata. Examples checked include Paginator's `rows`, `page`, `pageIndex`, and `rowsPerPageOptions`; Table's `sortField`, `sortOrder`, `rows`, `totalRecords`, and `rowsPerPageOptions`; Button and IconButton's `clicked` output; Carousel's `value` and `page`; Tooltip's `appTooltip`, `uiTooltip`, and `orcTooltip`; and Stepper's `activeIndex`. These are declaration aliases, not property assignments, and are excluded from the defect list.

PickList's former assignments were not treated as synonyms. `onMoveAllToTarget` and `onMoveAllToSource` now mean a real enabled-item move of the entire backing list, while `onMoveToTarget` and `onMoveToSource` remain selected-only. All transfers preserve source order, append to the destination, ignore active filters by contract, retain disabled items in place, clear valid selections, emit one final aggregate selection snapshot after each successful movement, and stay quiet for empty/disabled-only/no-movement requests. List options expose separate source/target names, one roving tab stop, Arrow/Home/End movement that skips disabled or filtered options, Enter/Space selection, focus recovery after filtering/replacement, and focus-visible outlines. Focus recovery is computed once per filtered pane update, tracks actual option focus, uses the host owner document, cancels stale microtasks on successive requests/destroy/disable, clears ownership on explicit blur or external focus, and only recovers a detached owned option to a currently enabled neighbor. Whole-widget disabled state disables filters and keyboard interaction and removes option tab stops; re-enabling restores the first enabled entry. External invalid or disabled selections are pruned without transfer or selection-change emissions.

The table intentionally does not call a class method named `onItemClick` (for example Rating's handler) an Angular output alias. It also does not infer an alias from a naming convention alone.

## Excluded property aliases

- `PaginatorComponent`'s `rows`, `page`, and `pageIndex` point at backing signals, but the actual public names are separately registered by `rowsInput`, `pageInput`, and `pageIndexInput` with explicit aliases. The sealed metadata contains all three public inputs.
- `ContextMenuComponent.visible = this.open` is an internal signal convenience; `visible` is not documented as a supported binding and the sealed metadata intentionally registers `open`/`openChange`.
- `VirtualScrollerComponent.itemSize = this.itemHeight` is a class convenience. Current docs and metadata support `itemHeight`; the component does not declare `itemSize` as a public input, so this audit does not silently promote it to API.
- `SplitButton`'s `onMenuShow`/`onMenuHide` and `TieredMenu`'s `onItemClick` are real `output()` declarations and are present in metadata; they are not assignment aliases.
- Inherited metadata, canonical component re-exports, and method aliases were excluded. The tabs/stepper sources changed concurrently during the original audit; Stepper's explicit `activeIndex` declaration alias was checked. Freeze-23's package build/consumer checks now supersede the prior "next sealed build" caveat; no additional assignment alias is inferred because `activeIndex` is a registered model alias.
