Dropdown is a flat action menu: `children` is accepted for source compatibility but ignored, and its owning item remains actionable. Use `TieredMenuComponent` from `@ciag/orchestra/tiered-menu` for its supported submenu behavior (root items and one child level; deeper grandchildren are unsupported). Keep the trigger a real button. `menu` is a separate PrimeNG-style model/popup menu entry point. A `DropdownItem` has `label` and optional `id`, `icon`, `shortcut`, `danger`, `disabled`, `divider`, `action`, and deprecated `children`.
