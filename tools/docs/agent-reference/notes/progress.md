Finite values and marker positions clamp to their ranges. Indeterminate mode omits determinate range values; with `animation="none"` the circle shows a static partial arc. A blank `ariaLabel` uses the trimmed `label`, then `Progress`.

Variations: determinate vs indeterminate; semantic color; sm/md/lg/xl; segmented bar when `segments > 0`; custom colors only for a product-specific token not yet represented by the semantic variants.
