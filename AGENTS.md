Issues and specs live in GitHub Issues on `OpenCIAg/orchestra` — always pass `--repo OpenCIAg/orchestra` because `origin` points at the GitLab mirror. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs
